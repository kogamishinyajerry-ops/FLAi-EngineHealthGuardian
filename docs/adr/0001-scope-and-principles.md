# ADR 0001 — 范围与原则

- 状态:Accepted
- 日期:2026-08-12

## 背景
报告(独立战略研究报告,出于敏感性仅本地保留、不纳入公开仓库)给出 36 个月全量蓝图。v0 脚手架需要明确「现在做什么、不做什么、不可动摇什么」。

## 决策
1. v0 只交付:四脑骨架 + Evidence 脊柱 + EGT-margin 一个垂直切片(合成数据)+ CI。
2. **不可动摇的五条**:`docs/architecture.md` 顶层原则(advisory-only / LLM 不算状态 / 小数据路线 / Evidence 脊柱 / ABSTAIN 一等结果)。任何 PR 违反这五条必须先改本 ADR。
3. 真实数据接入、适航证据、跨航司学习等一律 deferred,但**留接口**。

## 后果
- 好:架构被真实切片验证,不被架构图验证;advisory-only 把安全/认证风险降到最低。
- 坏:很多模块是 stub,看起来「什么都能做但什么都半成品」。这是刻意的 —— 比铺开做半成品要安全。
